Sobre los Datos y la API

Información de la Fuente de Datos

Los datos que alimentan este sitio web proceden de la interfaz de programación de aplicaciones (API) football-data.org.

  • Mantenimiento: Desarrollada y mantenida por Daniel Freitag.
  • Documentación oficial: Documentación de football-data.org.
  • Condiciones de uso y licencia: Utiliza un plan gratuito (*Free Tier*) con un límite de peticiones por minuto y la obligación de incluir el token de autenticación (`X-Auth-Token`). Requiere atribución visible al proveedor de los datos deportivos.
  • Peticiones realizadas: Se han realizado solicitudes HTTP GET para consultar información de competiciones, calendarios, clasificaciones y detalles específicos de los equipos de LaLiga.

Transformación de Datos: Del JSON al HTML

Para construir las fichas y los catálogos del sitio, los datos estructurados en formato JSON que devuelve la API se transforman de manera semántica en etiquetas HTML.

1. Fragmento real del JSON original


{
  "id": 86,
  "name": "Real Madrid CF",
  "shortName": "Real Madrid",
  "tla": "RMA",
  "crest": "https://crests.football-data.org/86.png",
  "founded": 1902,
  "clubColors": "White / Blue"
}

2. Equivalente en HTML semántico

El fragmento anterior se ha transformado en el siguiente marcado estructurado dentro de la ficha del equipo:


<article>
    <header>
        <h1>Real Madrid CF</h1>
        <figure>
            <img src="../assets/img/real-madrid.png" alt="Escudo oficial del Real Madrid CF" width="150" height="150">
            <figcaption>Escudo oficial del Real Madrid CF</figcaption>
        </figure>
    </header>
    <section>
        <h2>Datos Identificativos</h2>
        <dl>
            <dt>Siglas / Ticker</dt>
            <dd>RMA</dd>
            <dt>Año de fundación</dt>
            <dd><time datetime="1902">1902</time></dd>
            <dt>Colores del club</dt>
            <dd>White / Blue</dd>
        </dl>
    </section>
</article>
